# Object vocabulary

For every kept object choose one outline treatment and exactly one interior mark family. If an object is not listed, follow the same pattern: simplest recognizable silhouette from above, plus one mark that names it.

Write the plan as `object -> outline -> mark -> approximate size and position`.

## Vessels

| Object | Outline | Typical mark |
| --- | --- | --- |
| Plate | Two concentric loose loops (rim + well) | Optional ring of small ovals or dots between the loops if the real plate has a pattern or scalloped rim; otherwise none |
| Bowl | Two concentric loops, inner one close to the rim | Contents mark (spiral for soup/porridge, specks for grains) |
| Shallow dish / saucer | Double loop, narrow rim | The contents |
| Glass (water, wine base) | Rim loop + base loop + two side lines (mixed view) | Two or three tiny curved strokes for a liquid line or ice; or none |
| Mug / cup from above | Rim loop + small handle loop | Small loop or spiral for coffee/tea surface; a dense hatch accent only if it is the chosen accent |
| Cutting board | Soft rectangle, optional rounded handle with a hole loop | None |
| Pan / skillet | Single loop + long handle | The contents |
| Jar / bottle from above | Small double loop (lid/neck) | None |

## Utensils

| Object | Outline |
| --- | --- |
| Fork | One continuous outline of a long handle, widening neck, three or four tines as narrow loops |
| Spoon | Long thin handle ending in an oval bowl; inner smaller oval optional |
| Knife | Long narrow blade outline merging into a handle; one tiny line at the junction |
| Chopsticks | Two long, very thin tapered rectangles, slightly non-parallel |

Only draw utensils that appear in the photo or dish list.

## Dense hatch accent

Choose one, at most two, objects to receive a small, tight scribble or parallel-hatch fill. Prefer a small, naturally dark or contrasting element: a cheese wedge, chocolate, olive tapenade, seaweed strip, coffee surface, a jam dollop, a pepper grind patch. Fill only that small shape. Never hatch a large object.

## Repetition

Repeated items (olives, berries, cookies, grains) should vary slightly in size, angle, and spacing. Use five to twelve repeats, not dozens.
